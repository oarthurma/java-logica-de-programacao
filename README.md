\# Java - Lógica de Programação



Repositório com os exercícios que resolvo durante o curso \*\*Java primeiros passos: Lógica de Programação e Algoritmos\*\*, do professor Nélio Alves (Udemy).



O código de referência do professor está em \[acenelio/curso-logica-de-programacao-java](https://github.com/acenelio/curso-logica-de-programacao-java). Este repositório contém as \*\*minhas\*\* soluções: eu tento resolver primeiro e só depois comparo com a resolução do curso.



\## Estrutura



| Projeto | Conteúdo |

|---|---|

| `beecrowd-exercicios` | Exercícios do BeeCrowd (antigo URI), um arquivo por problema: `BeeCrowdXXXX.java` |

| `exercicios-resolvidos` | Exercícios propostos em aula |

| `curso\_programacao` | "Lousa" usada durante as aulas para testes e explicações |



Cada pasta é um projeto do Eclipse.



\## Convenção para o BeeCrowd



No repositório, cada exercício fica numa classe com o número do problema (por exemplo, `BeeCrowd1115`). Na hora de enviar ao BeeCrowd, renomeio a classe para `Main` \*\*só no site\*\*, sem alterar o arquivo local.



\## Tecnologias



\- Java 8 (nível de compilação 1.8)

\- Eclipse IDE



\## Como abrir no Eclipse



1\. Clone o repositório.

2\. No Eclipse: \*\*File → Import → General → Existing Projects into Workspace\*\*.

3\. Selecione a pasta do repositório e marque os projetos.
